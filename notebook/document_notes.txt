# 2. LangChain `Document`

```python
from langchain_core.documents import Document
```

A LangChain `Document` is a standard structure for representing a piece of data.

It mainly contains:

```text
Document
├── page_content
└── metadata
```

Example:

```python
doc = Document(
    page_content="this is the main text content I am using to create RAG",
    metadata={
        "source": "example.txt",
        "pages": 1,
        "author": "Krish Naik",
        "date_created": "2025-01-01"
    }
)
```

### `page_content`

Contains the actual document text.

### `metadata`

Contains additional information about the document.

Examples:

```text
source
page
author
date
document type
```

### Interview point

> **`page_content` contains the actual data, while `metadata` contains information about that data and can be used for filtering, tracking, and citations.**

# 4. `TextLoader`

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader(
    "../data/text_files/python_intro.txt",
    encoding="utf-8"
)

document = loader.load()
```

`TextLoader` loads a **single text file** and converts it into LangChain `Document` objects.

Flow:

```text
python_intro.txt
       ↓
   TextLoader
       ↓
LangChain Document
```

### Important

`loader.load()` actually performs the loading operation.

---

# 5. `DirectoryLoader`

```python
from langchain_community.document_loaders import DirectoryLoader
```

Used when you want to load **multiple files from a directory**.

```python
dir_loader = DirectoryLoader(
    "../data/text_files",
    glob="**/*.txt",
    loader_cls=TextLoader,
    loader_kwargs={
        "encoding": "utf-8"
    }
)
```

### Important parameters

**`path`**

→ Directory to search.

**`glob="**/*.txt"`**

→ Match `.txt` files, including files in subdirectories.

**`loader_cls=TextLoader`**

→ Use `TextLoader` to process each matched file.

**`loader_kwargs`**

→ Arguments passed to `TextLoader`.

# 8. `PyMuPDFLoader`

```python
loader_cls=PyMuPDFLoader
```

Uses **PyMuPDF** to extract content from PDFs and convert it into LangChain `Document` objects.

Then:

```python
pdf_documents = dir_loader.load()
```

loads the PDFs.

Conceptually:

```text
PDF
 ↓
PyMuPDFLoader
 ↓
LangChain Documents
```

PDF pages are generally represented as separate documents containing page-level content and metadata.

# 9. Why Metadata Matters in RAG

Suppose you retrieve a chunk:

```text

```

Metadata can tell you:

```text

```

This becomes useful for:

* Source citations
* Filtering
* Debugging retrieval
* Tracking document origin
* Access control

Example:

```text
Query
 ↓
Retriever
 ↓
Relevant Chunk
 ↓
Metadata
 ↓
```

# 10. Data Ingestion vs Chunking

This distinction is important.

### Data Ingestion

Gets data **into LangChain's document format**.

```text
PDF/TXT/Web
    ↓
Document Loader
    ↓
Document
```

### Chunking

Splits large documents into smaller pieces.

```text
Document
    ↓
Text Splitter
    ↓
Chunk 1
Chunk 2
Chunk 3
```

So this notebook mainly covers **ingestion**, not the complete RAG pipeline.
